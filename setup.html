Setup

Four steps. Then he's awake.

Jager is free and MIT licensed. You bring the keys and run it anywhere: a laptop, a Raspberry Pi or a small server.

1

Get a Zernio key

Create a Zernio workspace, connect the accounts Jager should look after, and create an API key. Zernio also gives you the channel Jager talks to you on.

Zernio quickstart · Connecting accounts

2

Pick your channel

WhatsApp

Add a WhatsApp number in Zernio. Messages from Jager and your replies flow through it.

Telegram

Create a bot with BotFather, connect it in Zernio, press Start. Buttons and slash commands work.

Zernio Telegram docs

3

Add an AI key

Use OpenRouter for reading comments, drafting replies and understanding your messages. Add Runware for image jobs. Pick any model, cheap or clever.

4

Run it

.env
# the whole config
ZERNIO_API_KEY=zk_...
OPENROUTER_API_KEY=sk-or-...
RUNWARE_API_KEY=            # optional
JAGER_CHANNEL=telegram      # or whatsapp
JAGER_MODEL=openai/gpt-4o-mini
JAGER_TIMEZONE=Europe/Lisbon
JAGER_RECAP=sunday 10:00
terminal
$ git clone github.com/paulfxyz/jager
$ cd jager && cp .env.example .env
$ docker compose up -d
✓ Jager is awake. Say hi on Telegram.

Example config. Names follow the repository on GitHub.

What does it cost?

Jager is free. You pay your providers directly for what you use: Zernio for the connections and your AI provider for tokens. Check each provider's current pricing before you start.
