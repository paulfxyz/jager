# Security policy

Jager can delete things, so we take security seriously and we like being told.

**Please do not open a public issue for a vulnerability.** Email **ask@jager.social** with the subject "security", describe what you found, how to reproduce it and the impact. You will get an answer within a few days. Fixes ship as a patch release with credit if you want it.

In scope: signature verification, owner checks, confirmation bypass, prompt injection that causes an action, secret leakage, SQL injection, the Docker image.
Out of scope: attacks that need control of your Zernio account, your server or your chat account (see the "What is NOT protected" section of [docs/SAFETY.md](docs/SAFETY.md)).

Supported versions: the latest release.
