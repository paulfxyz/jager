Installation

Quatre étapes. Puis il se réveille.

Jager est gratuit et sous licence MIT. Tu apportes les clés et tu le fais tourner où tu veux : un portable, un Raspberry Pi ou un petit serveur.

Avant de commencer

  • Un compte Zernio (pour connecter tes comptes sociaux et un canal de chat)
  • Une clé OpenRouter (et en option une clé Runware)
  • Un numéro WhatsApp ou un compte Telegram pour parler à Jager
  • Une machine qui reste allumée : portable, petit serveur ou Raspberry Pi, avec Docker

Que se passe-t-il quand tu écris à Jager

  1. Tu envoies un message sur WhatsApp ou Telegram.
  2. Zernio le transmet à ton Jager via un webhook.
  3. Jager demande à ton modèle d'IA ce que tu veux dire : récap, suppression, réponse ou sprint.
  4. Jager l'exécute via Zernio sur tes comptes, après confirmation si c'est une grosse suppression.
  5. Il te répond dans le même chat, puis se rendort.
1

Récupère une clé Zernio

Crée un espace Zernio, connecte les comptes dont Jager doit s'occuper et crée une clé API. Zernio te donne aussi le canal sur lequel Jager te parle.

Démarrage Zernio · Connecter des comptes

2

Choisis ton canal

WhatsApp

Ajoute un numéro WhatsApp dans Zernio. Les messages de Jager et tes réponses passent par là.

Telegram

Crée un bot avec BotFather, connecte-le dans Zernio, appuie sur Start. Les boutons et les commandes avec / fonctionnent.

Doc Telegram de Zernio

3

Ajoute une clé IA

Utilise OpenRouter pour lire les commentaires, rédiger les réponses et comprendre tes messages. Ajoute Runware pour les images. Choisis le modèle que tu veux, économique ou brillant.

4

Lance-le

.env
# toute la config
ZERNIO_API_KEY=zk_...
OPENROUTER_API_KEY=sk-or-...
RUNWARE_API_KEY=            # optionnel
JAGER_CHANNEL=telegram      # ou whatsapp
JAGER_MODEL=openai/gpt-4o-mini
JAGER_TIMEZONE=Europe/Lisbon
JAGER_RECAP=sunday 10:00
terminal
$ git clone github.com/paulfxyz/jager
$ cd jager && cp .env.example .env
$ docker compose up -d
✓ Jager est réveillé. Dis bonjour sur Telegram.

Exemple de config. Les noms suivent le dépôt sur GitHub.

Combien ça coûte ?

Jager est gratuit. Tu paies directement tes fournisseurs pour ce que tu utilises : Zernio pour les connexions et ton fournisseur d'IA pour les tokens. Vérifie les tarifs actuels de chacun avant de commencer.
